# 線上英雄卡

依照[角色創建](character/rank-pax-attributes.md)的七個步驟填寫，PAX 花費、決心值、防禦等數值會自動計算，違反規則的地方會列在「規則檢查」裡。填寫內容會自動保存在這台裝置的瀏覽器中；要換裝置或備份，請用「匯出 Excel」，之後可以再「匯入 Excel」繼續編輯。
